프로그램을 다운로드하고 실행하세요

설치 과정 없이 실행하면 접속 코드가 나옵니다. 이 코드를 기사에게 알려주시면 원격 접속이 시작됩니다.

원격 지원 프로그램 다운로드 Windows · 실행만 하면 됩니다
프로그램 실행 화면에서 간단한 이용 동의와 연락처를 확인합니다.

사용 방법

1
다운로드 후 실행

받은 파일을 더블클릭하면 6자리 접속 코드가 표시됩니다.

2
접속 코드 알려주기

화면의 6자리 코드를 기사에게 알려주세요.

3
잠시 대기

연결되면 기사가 화면을 보며 도와드립니다.

4
완료 후 종료

작업이 끝나면 프로그램을 닫아 언제든 종료할 수 있습니다.

원격 지원 이용 안내

  1. 적법한 용도로만 사용 — 본 원격 지원은 정당한 기술 지원 목적으로만 사용되며, 타인의 기기 무단 접근 등 불법적인 용도로 사용하지 않습니다. 고객은 본인 소유이거나 정당한 권한이 있는 PC에 대해서만 지원을 요청합니다.
  2. 데이터 보호 한계 — 원격 지원 특성상 세션 중 화면·파일에 접근할 수 있어 데이터의 완전한 보호를 보장할 수 없습니다. 중요한 자료는 미리 백업해 주세요.
  3. 면책 — 원격 작업 중 또는 그로 인해 발생하는 데이터 손실·시스템 오류, 기기의 치명적 결함(하드웨어 고장 등)으로 인한 문제에 대해 책임을 지지 않습니다.
  4. 세션 녹화(품질관리·분쟁대비) — 원격 지원 세션은 작업 기록·품질관리·분쟁 대비 목적으로 기사 PC에 녹화될 수 있습니다.
  5. 개인정보(전화번호) 수집·이용 — 원격 지원 연락 및 본인확인 목적으로 전화번호를 수집하며, 지원 완료 후 파기(최대 6개월 보관)합니다.

자세한 동의는 프로그램 실행 화면에서 진행합니다 — 위 내용은 사전 안내입니다.

실행 시 경고가 뜨면

“Windows가 PC를 보호했습니다” 창이 뜨면 추가 정보 → 실행 을 눌러주세요. 정상 프로그램입니다. (백신이 막으면 잠시 허용해 주세요.)
